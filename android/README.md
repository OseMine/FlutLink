# FlutLink Android

FlutLink mobile client for the FlutCloud server: file browsing, sharing and
user administration on Android, built with Kotlin + Jetpack Compose
(Material 3) and the same FlutCloud-only policy as the desktop client — it
connects exclusively to the FlutCloud server (`FLUTCLOUD_URL`) and rejects
servers that do not run the FlutCloud Nextcloud app (`flutcloud-app/`).

> **This is a port.** The Android app is a port of the FlutLink desktop client
> (Tauri/Rust + Vue) to Kotlin/Jetpack Compose. It was generated by **opencode**
> and mirrors the desktop feature set — it is not a separate product and must
> stay behaviorally in sync with the desktop client.

## Structure

```
android/
├── gradle/libs.versions.toml    # version catalog (AGP, Kotlin, Compose BOM, OkHttp)
├── app/
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── res/                 # strings, themes, launcher icons, security config
│       └── java/com/flutcloud/flutlink/
│           ├── MainActivity.kt       # edge-to-edge host, theme wiring
│           ├── FlutLinkApplication.kt
│           ├── AppContainer.kt       # service locator: OkHttp, stores, session
│           ├── core/                 # AccountStore (EncryptedSharedPreferences),
│           │                         # SettingsStore (DataStore), SessionManager
│           ├── data/                 # FlutCloudApi (OCS), WebDavApi (PROPFIND/XML),
│           │                         # DTOs, HTTP client factory
│           └── ui/                   # Compose screens (Login, Files, Admin, Settings),
│                                     # navigation, ViewModels, M3 theme
```

## Feature parity with the desktop client

- **FlutCloud-only enforcement** — `FlutCloudApi.verifyServer` probes the
  `flutcloud` capability before an account is accepted.
- **Files** — WebDAV browsing (PROPFIND), upload (Storage Access Framework),
  download, folder creation, rename, delete, global search (SEARCH),
  virtual-link (`resources`/`parts`) pairing, public share-link creation.
- **Admin** — OCS user administration: list/search, create, delete,
  enable/disable, quota presets.
- **Security** — tokens live in `EncryptedSharedPreferences` (Android
  Keystore), account metadata in a separate preferences file, same split as
  the desktop keyring design. No token is ever logged or persisted in plain
  text.

## Build

Prerequisites: JDK 17, Android SDK (`ANDROID_HOME` or `android/local.properties`).

```
cd android
./gradlew :app:assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

## Tests

JVM unit tests live in `app/src/test/` (WebDAV multistatus parsing, OCS meta
parsing, `AccountStore` roundtrip, `SessionManager` account switching/removal):

```
./gradlew :app:testDebugUnitTest
```

The FlutCloud server URL is compiled into `BuildConfig.FLUTCLOUD_URL`. Override
it for local development with:

```
./gradlew :app:assembleDebug -PflutcloudUrl=https://your-server.example
```
